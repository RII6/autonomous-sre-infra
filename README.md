# autonomous-sre-infra
Автономная SRE-инфраструктура с функцией самовосстановления (Self-Healing), защитой от DDoS/брутфорса и встроенными DevSecOps-практиками.


Этот проект — исследовательский стенд отказоустойчивой инфраструктуры, построенный по принципам SRE и DevSecOps. Главная идея заключается в создании системы, которая не просто собирает метрики, но и активно реагирует на инциденты без участия человека.

Инфраструктура имитирует работу "иммунной системы": она способна самостоятельно обнаруживать аномалии (высокая нагрузка, сканирование портов, компрометация контейнеров) и применять сценарии автоматического восстановления (Self-Healing) — от динамического масштабирования до изоляции угроз на уровне сетевого экрана.

Ключевые возможности:
Self-Healing: Автоматическое горизонтальное масштабирование приложения при скачках трафика.
Active Defense: Интеграция Custom Honeypot для отлова атакующих и автоматического бана вредоносных IP-адресов.
DevSecOps Pipeline: Непрерывная проверка исходного кода (Semgrep) и сканирование Docker-образов на уязвимости (Trivy) в GitHub Actions.
Observability: Полная телеметрия кластера с использованием Prometheus и визуализация доказательств защиты в Grafana.
Chaos Control Center: Веб-интерфейс для симуляции инцидентов (DDoS, брутфорс, отказ узлов) в реальном времени.
